# LakeLens 🌊

**Know before you go.** Closure predictions, one-tap crowd reports, parking and accessibility for Florida's springs and state-park swim areas. Built at SASEhack 2026 by the team behind [BeachLens](https://beachlens.net).

> Work in progress — full README (architecture, data sources, how prediction and reports work) lands at the end of the hackathon.

## Run locally

```bash
cp .env.example .env.local   # fill in Supabase keys
npm install
npm run dev
```

## Stack
Next.js 16 (App Router) · TypeScript · Tailwind v4 · Supabase (Postgres, Edge Functions, pg_cron) · MapLibre GL + OpenFreeMap · Vercel

## Disclaimer
Informational only. Conditions change quickly — follow posted rules and park staff.
